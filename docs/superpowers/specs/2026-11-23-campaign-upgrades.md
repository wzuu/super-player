# 战役首页与局内成长

本轮覆盖 #8、#20、#15、#13、#24、#12、#11。另以 #27 记录玩家在地下实验室遇到的镜头翻转。

- 首页根据已登记关卡和实际存档生成主视觉、成绩与解锁状态。横向关卡列表支持方向键。仅进入收藏时初始化三维资源。发行目录保留原有的相对路径。
- 操作和画面偏好跟随设备。战役进度、军需、改装和携带选择跟随存档。新的战役生成独立存档，原有存档仍可切换。本机 SQLite 通过新增表升级，静态站点复用 IndexedDB 的 settings 对象仓库。
- 每一分已撤离宝物价值对应一点军需点。可购买有携带上限的消耗品与一次性永久改装。领取时扣库存，免费配给另计。胜利结算和返还物资在同一事务内完成，既有对战 ID 用于去重。
- 战场将 F 绑定为交互，Q/E 为技能，1/2 为道具。难度调整只影响玩家承受的伤害。自动画质使用持续低帧和稳定高帧两种窗口控制档位，模拟时钟沿用共享固定步长。
- 第三、六、九关默认使用坚守、护送、限时撤离。所有关卡可选择传统围剿或无尽行动。胜利仍触发既有战役解锁流程，无尽模式以失败结算。各主题的移动策略复用碰撞、视线和寻路。
- 发布策略沿用仓库试玩开关。回滚时恢复原运行时与首页即可，旧版可继续读取原有战役和外观表。
