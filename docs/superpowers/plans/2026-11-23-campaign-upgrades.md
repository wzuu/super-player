# 实施与验收

1. 用锁定鼠标的独立输入样本检查镜头俯仰、水平转动与警报切换。
2. 检查首页在 1280×720 和 1920×1080 的布局、焦点、存档切换。冷缓存记录列表、历史和收藏的引擎请求次数。
3. 验证设置持久化、键盘改绑、手柄输入映射和画质升降档。检查 HUD 的实际渲染计数。
4. 验证按进度解锁、免费配给、军需兑换和枪械改装。覆盖失败、胜利返还和重复提交，分别在 SQLite 与 IndexedDB 运行。
5. 通过真实关卡入口检查围剿和变体目标。无尽模式跨过波次边界。检查 80 只以上凶兽的实帧记录。
6. 运行 Node 回归、完整打包和浏览器套件。在一个 PR 列出对应 issues，将各自的修复和验证证据回填。
