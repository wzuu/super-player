# 凶兽可见性、模型与模拟性能验收

2026-11-24。在 960 × 540、中画质下，UHD 630 和 GTX 1060 均能在 160 只全部入镜的密集模型样板中达到约 60 FPS。在允许兽群追击的开阔样板中，两卡分别为 59.99 和 58.70 FPS。镜屋是平均帧率最低的样板，分别为 56.85 和 57.44 FPS。保留现有战役遇敌数量、波次与对象池容量。192 只池仅用于本次压测。

## 设备与方法

同一台 Windows 双显卡机器，分别指定低功耗和高性能 GPU，并从 WebGL 核对 Intel UHD Graphics 630、NVIDIA GeForce GTX 1060，两者均走 ANGLE D3D11。使用无头 Chrome 158.0.8127.36、DPR 1、固定种子 750077。旧版为 `6446b44`，新版运行代码为 `1685715`。M4 未实测，其他分辨率、画质和持续热负载下的结果也未采集。

样板使用游戏的绘制与武器循环。除独立的原 96 只霰弹用例外，每个样板先预热 30 帧，在连续步枪射击下采集 90 个真实 RAF 间隔，每个间隔推进 1/60 秒模拟时间，期间实际开火 15 次。平均 FPS 取总帧数除以总耗时，P95 取该轮帧时间第 95 百分位。另采 24 帧才启用计数钩子。提交数为最后一个诊断帧可能需要的本体数，模拟数为诊断窗口每步平均活体数，旧版无分项计数时读取末帧活体数。候选包围体、相机内中心、玩家实际无遮挡可见是不同口径。

高可见样板沿雨城架设测试平台。`open` 前排 6 只暂时眩晕，其余可正常感知和移动。`dense` 固定 48 个近距离位、48 个中距离位，并将末位首领置于近处。全体暂时眩晕以维持几何负载。两者的计时窗口每帧均提交全数本体，诊断窗口每帧均验证全数中心在相机内。室内、镜屋和斜梁使用各自实际地形。另从主线任务推进至第一关服务器机房与第三关钟楼南街，在实际增援高峰开始取样。这两场各投放 100 只、分批入场，测试峰值分别为 14 和 16。

## 原 96 只霰弹与导电压力

重用武器验收的 12 × 8 湿身幼体队列、霰弹射击与导电连锁，停住 AI 单步，只保留该用例原有的武器、反应和绘制负载。每个显卡、版本独立运行 5 轮，每个条件 52 帧，舍去前 8 帧。下表是五轮各自的中位帧时和 P95 再分别取中位。括号列五轮 P95 范围。单位均为 ms。

| 设备 | 条件 | 旧版中位 / P95（范围） | 新版中位 / P95（范围） |
| --- | --- | --- | --- |
| UHD | 霰弹 | 16.7 / 16.9（16.8–17.0） | 16.7 / 16.9（16.9–17.0） |
| UHD | 霰弹 + 导电 | 16.7 / 16.9（16.8–17.0） | 16.7 / 16.9（16.8–17.0） |
| GTX | 霰弹 | 16.7 / 16.8（16.8–16.9） | 16.7 / 16.8（16.8–17.1） |

四组中三组 P95 中位持平。GTX 导电从 16.8 增至 16.9 ms，严格按“P95 不劣化”仍有 0.1 ms 差异。两版本的五轮范围重叠。以上仅使用独立复跑的 20 条记录，未混入主矩阵的单次旧样板结果。

高密度样板两卡都选入 8 只普通近模和 1 只近模首领。主通道逐帧峰值为 27 次调用、105,124 个三角，低于目标 40 次、150,000 个三角。统计包含身体、活动部件、发光、血条、标记、残影和投影所在批次。反射单列，最终版整帧计时包含其成本。此样板整场景均值为 97.7 次调用、142,108 个三角。镜屋在最终版每帧另有约 3.8 次反射调用和 6,586 个反射三角。

UHD 高密度样板中，近模保留漫反射细节时与增加共享程序高光贴图后均为 60.004 FPS，P95 从 17.0 至 16.9 ms。两者主通道均为 22.5 次调用、87,603 个三角，矩阵写入均为 753 次、52,852 字节。保留共享高光图。没有单独 GPU 着色器计时，GTX 未另做材质开关对照。四种原型的 4 米第一人称实拍和动作见[五米内模型对照](beast-lod-poses.webp)，预算、滞回与相机优先级的断言见[模型回归](../tests/beast-lod.test.mjs)。

## 数据与复现

归档共 94 条 JSONL 记录。`series=matrix` 为 69 条主矩阵，`wall` 为 5 条墙体验证，`legacy-repeat` 为 20 条独立复跑，`trial` 区分轮次。缺失或 null 的分项表示当次未采集，旧版没有新版的模拟分项。主通道峰值只在有相应字段的记录中读取。[原始采样数据](herd-samples.jsonl) · [Python 入口](../tests/herd_performance.py) · [机位、分项和口径](../tests/herd_sample.js)

两个版本都先用各自的 `npm ci` 和 `npm run build` 打包。在新版目录运行下列命令，示例把旧构建放在相邻的 `../baseline`。更换 `--gpu` 可复测另一块显卡。原 96 只复跑需对每款显卡重复最后一条 5 次。

```sh
python level-kit/tests/herd_performance.py --baseline ../baseline --gpu integrated --modes baseline final --samples open indoor dense mirror tower machine-room street
python level-kit/tests/herd_performance.py --gpu integrated --modes off cull lod --samples indoor open dense mirror --sizes 160
python level-kit/tests/herd_performance.py --gpu integrated --modes diffuse --samples dense
python level-kit/tests/herd_performance.py --gpu integrated --modes off frustum cull full-upload final --samples wall
python level-kit/tests/herd_performance.py --baseline ../baseline --gpu integrated --modes baseline final --samples legacy96
```
