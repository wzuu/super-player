# 关卡 UI 布局规范

以第三关《雨夜废城》的桌面游玩画面为基准。长时间移动射击时，玩家可以用固定的视线路径读取目标、位置和资源。中央视野优先留给准星、来袭敌人和当前可执行的交互。

地面任务用小地图绿线和场景菱形指示下一处能走到的转角，动态门开启后更新。跨楼层目标指示高度和升降机。附近敌人接战时隐去路线，伤害方位、首领弱点和低弹药提示仍可见。实验室首领房的青色标记代表破甲脉冲，金色侧房和「可选搜集」读数用于战利品。

## HUD 布局

| 位置 | 内容 | 显示规则 |
| --- | --- | --- |
| 左上 | 当前区域、任务、击杀进度、已收集宝物数 | 游玩时常驻。任务随首领、道具、击杀和撤离阶段更新 |
| 右上 | 固定北向小地图 | 游玩时常驻。红点是普通凶兽，橙色标记表示首领或传送门，浅青箭头是玩家 |
| 上方中央 | 首领血条、关卡状态 | 独立堆叠。首领进入提示范围时显示血条，关卡状态可显示剩余时间或体温等数值与量表，并给出操作提示 |
| 正中央 | 准星、命中与击杀反馈 | 命中变为橙色，击杀变为红色并放大。交互、拾取和安全区提示在准星下方共用一行 |
| 视野边缘 | 受击红弧与近身三角 | 屏幕上方为正前、右侧为正右，转身时同步换算方位。红弧合并同方向短间隔命中，约 0.8 秒淡出。三角显示 5 米内最近四只无遮挡凶兽，由黄转红 |
| 左下 | 生命、体力 | 生命用绿色，体力用蓝色。蹲伏等当前姿态可用短标签 |
| 右下 | 机关枪、弹匣、备用弹药、换弹计时 | 当前弹匣数字最醒目。换弹及缺弹提示用橙色 |

使用桌面三列网格，左右上角向外对齐，中央列留给状态。790 CSS 像素及以下切成两列，状态移到任务和小地图下一行。压缩视口时小地图缩小，角落信息保留原有读取顺序。紧凑窗口高度在 575 CSS 像素及以下时，首领与关卡状态并排，给准星保留空间。鼠标锁定玩法以键鼠为前提。

任务第一行说明此刻可执行的动作，第二行显示剩余人数或时限，以及目标方位、距离和楼层。阶段改变时左上短暂显示“目标更新”。场景与北向小地图的青绿色菱形共用当前任务坐标。护送模式另以圆点标出无人机，受损后改变颜色。EMP 期间隐藏任务方向与常规地图，恢复后显示当前阶段。

命中、弱点、击杀和爆头击杀使用不同的准星标记与音高。侧边显示连杀，瞄准附近精英时显示词缀。首领血条显示阶段和破甲进度。射击震动和受击震动各自读取玩家设置，断电时保留既有生命暗角与警报音规则。

## 样式与交互

- 采用第三关的工业仪表样式。半透明深蓝黑面板 `#09131D`，正文 `#E9F4F7`，次要信息 `#9DB2C0`，青绿主操作 `#79F3E0`，橙色警报 `#FFAD73`，危险红色 `#FF626D`。
- 正文沿用第三关系统字体、苹方、微软雅黑回退栈，本项目以既有字体为准。弹药、计数和按键用 SF Mono、Consolas、Liberation Mono 等宽回退栈。
- 开场、暂停、胜利和失败复用左置模态菜单，背景保留场景。开场和暂停展示实际可用的按键，结束页展示击杀、带回件数和价值。通过战役进入时可返回首页。胜利保存后显示下一关入口，保存失败时显示重试。
- 主题可改变场景、名称、任务文案、威胁内容与小地图底图色。通过共享状态位放置与玩法相关的信息。状态位隐藏时不占空间，特殊控制仅在启用时出现在操作说明。
- 破裂预警、进水、封闭等关键变化使用同一通知入口。HUD 的读屏通知区播报状态切换，视觉倒计时独立更新。
- 断电机制可暂时隐藏常规战斗读数和准星，并在小地图原位置显示信号中断。共享状态位保留事件名称和恢复倒计时。
- EMP 预警时照常显示；断电时关闭方向红弧与近身三角，保留受击声音与生理反馈。恢复供电时按当前威胁重新显示。断电期间的命中仅在当时反馈。生命低于 30% 时血量读数转红，红色暗角缓慢脉动。首页“显示受击方向”控制受击红弧。近身三角独立提示视线内的凶兽，受击震动强度控制约 0.15 秒的视角偏转和视野收缩。
- 统一布局维护在 [preview.html](preview.html)，HUD 状态维护在 [ui.mjs](src/ui.mjs)。生成独立 HTML 时沿用同一模板。

## 验收

战前准备面板依次显示行动规则、技能与道具携带量，以及可折叠的装备调整和补给站。任务切换时按本关规则更新说明。较宽窗口左右并排，窄窗口纵向滚动，底部出发按钮保持可见。技能键和道具键显示当前存档实际绑定。离线练习展示默认配给。

- 在 1440 x 900 检查四角、准星、首领血条和关卡状态同时出现时互不遮盖。
- 红点瞄准由 `preferences.mjs` 的 `RED_DOT_AIM_ENABLED` 统一控制，目前关闭。第一人称和肩后视角都使用普通准星，玩家可按视角键切换。首页隐藏瞄准设置，教程在暂停练习后直接进入射击练习。
- 换弹时武器下移，准星外围显示换弹剩余比例圆弧，装填完成后圆弧消失。EMP 断电时隐藏中心准星和换弹环。
- 开场和暂停菜单显示存档设置中的实际键位。支持蹲伏或深入的场景分别显示对应说明。音效状态仅在首页显示，局内用当前绑定的快捷键切换，解除静音后恢复主音量。
- 在紧凑窗口确认中央状态进入第二行，小地图与任务保持可读。
- 验证开场、进入、Esc 暂停、继续、胜负结算及不同关卡的标题和操作说明。
